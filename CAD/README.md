# Contenido de esta carpeta `CAD`

En esta carpeta están contenidos los archivos cad desarrollados como entregables para el proyecto.


1. **Bittle-X.zip:** Es la carpeta descargada resultado de la edición de otro archivo público, este contiene los archivos en bruto utilizados para la visualización tridimensional en el archivo `BittleApp.m` desarrollada también como entregable.

    El archivo desarrollado en Onshape se encuentra en el siguiente link: [Documento de Onshape - Bittle X](https://cad.onshape.com/documents/aa146b1b316fcc2521a6efca/w/1c1aa7bd841d608ee8755e2c/e/5f3c6039ba4c7f4a15012426?renderMode=0&uiState=6af262322a449245c8d36f08). Se recomienda la descarga del archivo URDF con la configuración `STL` para el formato de geometría, `Binary` para formato STL y `Fine` para la resolución.


2. **BaseCalibracionBittle:** Contiene los archivos desarrollados durante la edición de la base de calibración. Estos archivos .ipt son resultado de una conversión de archivos .stl a .ipt mediante Autodesk Fusion. Cada archivo contiene la versión editada como sólido secundario. Para ver la versión original solamente se requiere habilitar la vista de este sólido en la carpeta de `Solid Bodies` en la ventana lateral de Autodesk Inventor.

    Los archivos originales fueron obtenidos de la página proporcionada por el fabricante: [Base de Calibración](https://makerworld.com/es/models/1523424-calibrate-stand-for-bittle-x-bittle-x-arm-robots#profileId-1596686).
