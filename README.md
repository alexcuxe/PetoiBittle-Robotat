# Contenido de este repositorio

**Proyecto:** Integración del Robot Cuadrúpedo Petoi Bittle (Bittle X / Bittle X V2) al Ecosistema Robotat (Laboratorio CIT-116, Universidad del Valle de Guatemala).

## Contenido de las carpetas

1. **CAD:** Contiene todos los archivos CAD desarrollados para el entregable final de la base de calibración y la simulación tridimensional, además de los enlaces a los archivos originales.
2. **Pruebas_iniciales_serial_alambrica:** Esta carpeta resume las primera pruebas realizadas mediante comunicación alámbrica serial USB con el robot. Contiene los archivos extraídos del repositorio oficial de OpenCat, necesarios para replicar las pruebas y verificaciones del firmware. Nota: de ser necesarios dirigirse al [Repositorio Oficial de OpenCat](https://github.com/PetoiCamp/OpenCat-Quadruped-Robot).
3. **Resultados_MATLAB:** Esta carpeta contiene los entregables del proyecto de graduación, con relación al software desarrollado en MATLAB, así como la adecuación del módulo ESP-WROOM-02D complementaria para Arduino IDE.
